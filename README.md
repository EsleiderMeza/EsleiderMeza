### 🚀 Proyectos destacados

Desarrollados de forma independiente para clientes reales, cubriendo todo el ciclo: requerimientos, desarrollo, despliegue e infraestructura.

**🤖 Agente de IA para atención al cliente (WhatsApp + RAG)**
Flujo en n8n conectado a Chatwoot y WhatsApp Cloud API, con base de conocimiento vectorial en Supabase/PostgreSQL para responder preguntas, capturar datos de clientes y gestionar citas de forma autónoma.

**📅 Sistema de agendamiento para estudio de pilates**
Aplicación web de gestión de clases con backend Node/Express y PostgreSQL: reservas, paquetes de créditos compartidos, bloqueo de horarios, gestión de profesores y frontend a medida con la identidad visual del cliente.

**🧩 Generador de tareas para Azure DevOps con IA**
Script en Python que usa LLMs (Ollama y APIs de proveedores externos) para agrupar criterios de aceptación de historias de usuario en tareas de desarrollo coherentes.

**🐳 Infraestructura propia para automatizaciones**
Despliegue y administración de un VPS con Docker Swarm, Portainer y Traefik para alojar n8n, Chatwoot, PostgreSQL y Redis, con integración de funciones serverless en AWS Lambda para procesos de Zoho.
